# Снимки 3D-сцен

PNG-файлы сохраняются кнопкой камеры над канвой редактора.
Имя содержит ID проекта, время UTC и уникальный идентификатор.
Изображения не добавляются в Git.

При запуске из исходников путь задан в `backend/src/WebApi/appsettings.Development.json`.
Docker Compose подключает эту папку к `/app/screenshots` контейнера бэкенда.
Путь сервера можно переопределить настройкой `Screenshots:Directory`.
